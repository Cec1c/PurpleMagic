# OpenList 天翼下载源

登录器 1.0.10 支持在原签名 APP、资源路径上协商天翼直链。客户端发送 `X-DNF90-Cloud-Transport: tianyi-v1`；网关只解析私有映射中已登记的 SHA256 和长度，返回短期 HTTPS 链接。客户端下载后继续验证完整长度、SHA256、签名以及压缩资源的解压后摘要。

OpenList 独立运行并管理天翼登录和 Token 刷新，网关通过回环地址访问其 API。部署在另一台机器时使用受限 SSH 隧道。网关与登录器均只接受经过验证的天翼下载域名 `cloudcube.wuxi.cn`；其他存储或新增域名需先验证再纳入。

Hub 可选配置：

```json
{
  "openlist_delivery": {
    "endpoint": "http://127.0.0.1:29449",
    "token_file": "/private/openlist/api-token",
    "artifacts_file": "/private/openlist/artifacts.json"
  }
}
```

映射格式为 `{"<64位SHA256>":{"path":"/mount/project/<64位SHA256>.blob","size":123}}`，APP 可使用 `.zip`。文件必须先上传并完整读回核对摘要。映射启动时加载；新增文件保留旧条目。OpenList 凭据、天翼 Token、私有映射与下载链接均不进入公开源码或日志。

1.0.9 及更早版本继续使用已有百度协议或原路径文件数据。必须先向旧客户端下载新版 APP，再让新版使用天翼直链；直接把旧请求跳转到天翼会被旧客户端拒绝。新客户端保留百度协商，兼容尚未启用天翼的网关。

响应头或读取数据连续 20 秒没有进展时，下载器保留断点、重新取链，最后尝试原路径数据。调用者取消仍立即取消；长度、范围、哈希或域名不合法时终止下载并丢弃不可信临时文件。签名清单读取总时限为 90 秒，保持原大小上限和防回滚校验。

上线验收：旧下载器获得新版 APP；新版获得网关 307、天翼 Range 206；实际下载器完整下载 APP 与当前全部资源；第二次资源规划为零。网关回源成功独立记录，不能代替天翼取链验收。
