# 账号黑钻

在 GM 页选择「黑钻贵族」，填写开通天数并确认。目标为当前角色所属账号，账号内所有角色共享；可输入 1–3650 天，或选择 7、30、90、365 天。

已开通时，从当前到期时间续期；已过期时，从现在开始计算。成功后页面显示新的到期时间，玩家重新登录游戏后更新黑钻状态。

网关提供账号级接口，支持尚未创建角色的账号：

- `GET /api/v1/accounts/{accountId}/premium`：当前黑钻及到期时间。
- `POST /api/v1/accounts/{accountId}/premium-grants`：`{"days":30}`，沿用 GM 会话、CSRF 和 `Idempotency-Key`。

写入沿用游戏现有的黑钻契约类型 17，并核对当前 PVF 注册的契约类型。同账号事务只更新黑钻到期时间和本次永久回执，重复提交不会再次增加天数；保留钱包、其他契约及所有历史回执。需要支持本接口的管理网关，无需修改数据库结构或游戏协议。
