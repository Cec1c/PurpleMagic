# 登录器系统托盘

点击右上角“最小化到托盘”，登录器收进 Windows 右下角通知区域。若图标被 Windows 折叠，可在“显示隐藏的图标”中找到 PurpleMagic。

使用 MyDockFinder 等任务栏工具时，图标显示在该工具的通知区域，例如顶部 Finder 栏。

- 点击托盘图标，或右键选择“打开登录器”，恢复窗口。
- 再次打开登录器也会恢复已有窗口。
- 右键选择“退出登录器”，或点击窗口关闭按钮，退出登录器。保护版退出时会结束本次关联的游戏。

收进托盘期间，下载、日志收集与反作弊监护继续运行。窗口恢复后保留原有页面和操作状态。普通版与保护版共用此行为，无需额外配置。

托盘图标只在最小化期间显示。Explorer 重建任务栏时会重新添加图标；图标添加失败时保留任务栏窗口，重建失败时恢复登录器窗口。

实现位于 Windows runner，沿用现有窗口消息和应用图标。隐藏窗口使用 `SW_HIDE`，不会触发关闭窗口或销毁 Flutter 引擎；托盘退出沿用现有 `WM_CLOSE` 生命周期。
